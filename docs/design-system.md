# Aasra AI — Design System: "The Digital Sanctuary"

> Generated by Stitch (Google Gemini) for the AasraAI project.

## 1. Overview & Creative North Star

The Creative North Star for this design system is **"The Digital Sanctuary."**

We are moving away from the cluttered, "utility-first" aesthetic common in senior-focused apps. Instead, we are building a premium, editorial-inspired environment that prioritizes dignity over mere utility. This system avoids the "toy-like" feel of oversized buttons by using **Sophisticated Scale** — balancing massive, legible typography with expansive negative space.

By leveraging intentional asymmetry and tonal layering, we create a layout that feels less like a technical interface and more like a high-end, tactile concierge service. Every interaction is designed to feel calm, deliberate, and authoritative, ensuring our users feel empowered rather than overwhelmed.

## 2. Colors & Surface Philosophy

The palette is rooted in trust and urgency, utilizing a sophisticated spectrum of blues and neutrals to guide the eye without causing cognitive fatigue.

### The Color Tokens

| Token | Value | Usage |
|-------|-------|-------|
| **Primary (Action)** | `#004D99` | Deep, authoritative blue for primary navigation |
| **Primary Container (Interaction)** | `#1565C0` | Core interactive blue for voice triggers and main CTAs |
| **Tertiary (Urgency)** | `#A10012` | Refined red for Emergency/SOS |
| **Surface** | `#F9F9F9` | Soft off-white to reduce screen glare |
| **On Surface** | `#1B1B1B` | Primary text — high contrast, not pure black |
| **On Surface Variant** | `#424752` | Secondary text |

### The "No-Line" Rule

Traditional 1px borders are **strictly prohibited** for sectioning. They create visual noise that confuses aging eyes. Boundaries must be defined through **Background Color Shifts**.

- Use `surface_container_low` (`#F3F3F3`) to define a section against a `surface` background.
- Use `surface_container_highest` (`#E2E2E2`) for inactive or secondary interactive zones.

### Surface Hierarchy & Nesting

Think of the UI as **Stacked Fine Paper**.

1. **Base Layer:** `surface_container_lowest` (#FFFFFF)
2. **Content Areas:** `surface_container` (#EEEEEE)
3. **Elevated Interactions:** `surface_bright` (#F9F9F9) sitting on a darker container

### The "Glass & Gradient" Rule

To elevate the assistant beyond a standard app, use a subtle **Signature Texture** on the main voice-activation button: a linear gradient from `primary` to `primary_container`. For floating modal overlays, apply **Glassmorphism** using a semi-transparent `surface` color with a 20px backdrop-blur to maintain context of the underlying screen.

## 3. Typography: The Editorial Scale

We employ a "Heroic Typography" strategy. **Plus Jakarta Sans** for headlines introduces modern, geometric friendliness. **Inter** for body copy provides functional clarity.

| Scale | Size | Usage |
|-------|------|-------|
| **Display-LG** | 3.5rem | Primary voice feedback and greetings |
| **Headline-LG** | 2.0rem | Main section titles (minimum for top-level labels) |
| **Title-LG** | 1.375rem | Bilingual sub-text (Hindi translations under English) |
| **Body-LG** | 1.0rem (~20sp) | Absolute minimum for any descriptive text (WCAG AAA) |

**Bilingual Treatment:** When displaying English and Hindi, the English text uses `on_surface`, while the Hindi translation directly below uses `on_surface_variant` at `title-md` scale.

## 4. Elevation & Depth

Depth is not about "pop"; it is about **Contextual Layering.**

- **The Layering Principle:** Avoid shadows for static cards. Instead, use a `surface_container_high` card on a `surface` background.
- **Ambient Shadows:** For the Emergency SOS button or floating Voice-Action buttons, use a shadow with a 40px blur, 4% opacity, and a tint of `primary_fixed_dim`. This mimics natural light.
- **The "Ghost Border" Fallback:** If high-contrast separation is required, use `outline_variant` at **15% opacity**. Never use 100% black or grey lines.

## 5. Components

### The Power Button (Primary CTA)
- **Height:** Min 80dp
- **Radius:** `xl` (1.5rem) or `full`
- **Interaction:** `primary_container` for resting, `on_primary` for label

### Photo Tiles (The Human Connection)
- **Size:** 88dp × 88dp circular tiles
- **Styling:** No borders. Use a 4dp `outline` in `surface_variant` only for placeholder state.

### Senior-Optimized Inputs
- **Touch Targets:** Every interactive element must have a minimum target of **64dp**
- **Input Fields:** `surface_container_highest` backgrounds with `outline` at 20%. Labels stay at `headline-sm` scale above the field — never floating inside.

### Cards & Lists
- **Rule:** Forbid divider lines
- **Separation:** Use 32dp of vertical white space between list items
- **Grouping:** Wrap items in a `surface_container_low` card with `lg` (1rem) corner radius

### Voice-First Input (The "Aura")
- **Size:** Min 88dp × 88dp circular trigger
- **Animation:** `surface_tint` pulse animation
- **Listening state:** Glassmorphism — semi-transparent `primary_container` with 20px blur

## 6. Do's and Don'ts

### ✅ Do
- Use high-contrast color pairings (`on_primary` on `primary`) to exceed WCAG AAA
- Prioritize "Voice-First" feedback — every visual change should have rhythmic pulse
- Use asymmetrical layouts for Hero sections to create editorial, premium feel
- Use `on_surface_variant` for helper text, but never below 1rem (20sp)
- Allow content to bleed off-center — intentional asymmetry creates editorial feel
- Use "Liquid Layouts" — containers must expand vertically to prevent text clipping

### ❌ Don't
- **Don't use 1px dividers** — they create visual noise and can be perceived as hair-line fractures by users with cataracts
- **Don't use "Grey on Grey" text** — if background is `surface`, text must be `on_surface`
- **Don't use icons without labels** — every icon must be accompanied by text in both English and Hindi
- **Don't use "Pure Black"** — use `on_background` (#191c1d) to keep the experience soft and premium
- **Don't use "Snackbars" that disappear too quickly** — seniors require 2x to 3x the standard time to process temporary messages
